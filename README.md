# Zytrix TCC

Repositório do projeto acadêmico **Zytrix**, plataforma de livestream.

## Versão principal

A versão web atual e recomendada está em [`Zytrix-HTML-CSS/`](./Zytrix-HTML-CSS/).

Ela usa HTML, CSS, JavaScript ES Modules, Firebase Authentication, Cloud Firestore, Twitch Embed e Vercel. A implementação anterior em Code Layers/TSX foi mantida no histórico e nas pastas existentes para referência do desenvolvimento do TCC.

Consulte [`Zytrix-HTML-CSS/README.md`](./Zytrix-HTML-CSS/README.md) para execução local, arquitetura, chat, Zy Coins, segurança e deploy.
