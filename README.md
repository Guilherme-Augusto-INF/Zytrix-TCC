# Zytrix

Plataforma de livestream desenvolvida como projeto de TCC.

## Tecnologias
- Figma Sites
- React / TypeScript
- Firebase Authentication
- Cloud Firestore
- Twitch Embed
- Git / GitHub

## Principais funcionalidades
- Cadastro e login
- Perfil de usuário
- Conversão de usuário em streamer
- Integração com Twitch
- Configuração de lives
- Iniciar e encerrar transmissões
- Lives em destaque
- Categorias e subcategorias
- Página individual de transmissão

## Estrutura
- `figma/` — projeto original do Figma Sites
- `code-layers/` — códigos React/TypeScript usados no Figma
- `firebase/` — regras e configurações do banco
- `docs/` — imagens e documentação

## Projeto
Desenvolvido em 2026 para fins acadêmicos.
